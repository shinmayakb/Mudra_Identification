# MudraNet

## Viewpoint-Invariant Bharatanatyam Mudra Recognition Using Joint Graph Convolutional Networks

MudraNet is an AI-based Bharatanatyam mudra recognition system that uses MediaPipe hand landmarks and Graph Convolutional Networks for real-time gesture recognition.

## Features

- Bharatanatyam mudra recognition
- Dual-hand gesture recognition
- 42 hand landmark extraction
- Viewpoint-invariant recognition
- Real-time prediction
- Web and mobile support

## Dataset

Bharatanatyam Mudra Dataset obtained from Kaggle.

- Approximately 45,572 RGB images
- 50 mudra classes

The dataset itself is not included in this repository.

## Technologies

- Python
- PyTorch
- MediaPipe
- OpenCV
- React
- Flask

## Model

The proposed architecture includes:

1. MediaPipe Landmark Extraction
2. JGCN
3. KGCN
4. Joint-Weighted Classification
5. Mudra Prediction

## Results

- Accuracy: 96.0%
- Real-time gesture recognition
